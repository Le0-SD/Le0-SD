### Leo

I build desktop tools, mostly on macOS.

Projects I keep coming back to:

- **[PixelPipe](https://github.com/Le0-SD/PixelPipe)** — macOS screen capture, app structure, input control, and local search exposed through a small command server.
- **[Lucid](https://github.com/Le0-SD/Lucid)** — continuous screen perception, memory, and control exposed through an MCP server.
- **[ShaderMIDI](https://github.com/Le0-SD/ShaderMIDI)** — a Metal shader instrument for live visuals, MIDI controls, Ableton Link sync, envelopes, and shader sets.
- **[OrganiVision](https://github.com/Le0-SD/OrganiVision)** — a visual project graph built from local screen memory, with nodes, edges, digests, and a hotkey overlay.

Most of my code is Swift, Metal, and TypeScript. I like tools that stay close to the OS and make the computer easier to steer.
