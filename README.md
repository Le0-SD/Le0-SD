### Hi, I'm Leo

Building tools that make AI useful on a real desktop, not in a chat box.

Currently working on:

- **Lucid** — continuous screen perception, memory, and control as an MCP server. Always-watching daemon with VLM captions and a vector store of what your screen has shown.
- **TaskPool** — shared task queue for collaborative Claude Code sessions. MCP server + live web dashboard + CLI, one process.

Themes I keep returning to: **on-device AI**, **macOS automation**, **MCP servers**, **AI ↔ desktop integration**, **privacy-first design**.

Mostly Swift and TypeScript. macOS-native where it matters.
